# Provider Integration Spec template

Every product spec records: available metrics; source and classification; permissions; identity; pools; units; window/reset semantics; API usage/cost and reporting delay; history; pagination/cursor; rate limits; 401/403/429 behavior; stable fields; fixture whitelist; forbidden storage; closed-client behavior; credential mutation; and manual verification.

An unverified field is `Unknown`, never zero, unlimited, or a guessed value.
