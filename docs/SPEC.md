# Usage.ai — техническое задание

Версия 0.1 · 2026-09-08 · статус: на согласование

## 1. Цель

Меню-бар приложение для macOS, которое показывает остаток лимитов ИИ-подписок
(Claude, Codex/ChatGPT, Antigravity) в одной панели. Функциональный аналог
UsagePal, написанный с нуля, для личного использования. Интерфейс на русском,
тема следует системной.

## 2. Область работ

**v1 (MVP)**
- Иконка в меню-баре (без иконки в Dock), панель под иконкой.
- Провайдеры Claude, Codex, Antigravity: лимиты (сессия / неделя / пулы), время
  сброса, план подписки.
- Автообновление по расписанию, ручное обновление, кэш последнего снапшота.
- Настройки: интервал, запуск при входе, видимость/порядок провайдеров, тема.
- Сборка `.dmg` локально и в GitHub Actions.

**v1.1**
- «Обзор использования»: доля токенов по моделям за Сегодня / Вчера / 30 дней
  из локальных логов.
- Antigravity через OAuth, когда IDE закрыт.
- Локальный (без сети) фолбэк лимитов Codex из session-логов.
- Опциональное автообновление OAuth-токена Claude (выкл. по умолчанию).

**v1.2**
- Уведомления (порог, темп расхода, сброс окна), глобальный шорткат,
  автообновление приложения, экспорт обзора.

**Вне области**: несколько аккаунтов на провайдера; другие провайдеры;
Windows/Linux; телеметрия; облачная синхронизация; подпись и нотаризация Apple.

## 3. Допущения (подтвердить)

- Mac на Apple Silicon, macOS 14+.
- Установлены и авторизованы: Claude Code (план Pro/Max), Codex CLI и/или
  Codex.app (ChatGPT Plus), Antigravity IDE (Google AI Pro).
- Один аккаунт на провайдера.
- Приложение только для себя: без Apple Developer ID, ad-hoc подпись.

## 4. Стек

Решение: **Tauri 2 (Rust) + Svelte 5 / TypeScript**.

- Ядро на Rust: HTTP — `reqwest`, Keychain — `security-framework`, парсинг —
  `serde`, планировщик — `tokio`, процессы — `sysinfo`.
- UI: Svelte 5 + Vite + TS, CSS-переменные (без UI-кита), иконки Lucide +
  брендовые SVG провайдеров.
- Плагины Tauri: tray (встроен), `tauri-nspanel` (панель как NSPanel),
  `positioner`, `store`, `autostart`, `global-shortcut`, `notification`,
  `updater`.

Почему не Swift: ~90 % работы (провайдеры, парсеры, UI) разрабатывается и
тестируется в Linux-песочнице; macOS нужен только для сборки (CI) и ручной
проверки. Swift потребовал бы Xcode на каждую итерацию. Почему не Electron:
в 5–10 раз тяжелее. Референс (UsagePal / OpenUsage) построен на Tauri — стек
проверен именно на этой задаче.

## 5. Архитектура

```
┌──────────────── Usage.ai.app ─────────────────┐
│ Frontend (Svelte)  ⇄ IPC ⇄  Tauri core (Rust) │
│  Panel / Settings            ├ scheduler      │
│                              ├ snapshot cache │
│                              ├ settings store │
│  tray icon / menu            └ providers ─────┼──▶ Keychain, ~/.claude, ~/.codex
└───────────────────────────────────────────────┘──▶ api.anthropic.com
                                                 ──▶ chatgpt.com
                                                 ──▶ 127.0.0.1 (Antigravity LS)
```

Cargo workspace:

- `crates/usage-core` — модель данных, трейт `Provider`, планировщик, расчёт
  темпа и статусов. Без зависимостей от Tauri → тестируется на Linux.
- `crates/usage-providers` — `claude`, `codex`, `antigravity`: чтение кредов,
  HTTP, парсеры, `fixtures/`.
- `src-tauri` — трей, окно, IPC-команды, кэш, настройки.
- `src` — Svelte-фронтенд. Режим `?mock=1` с фейковыми данными для разработки
  UI в обычном браузере.

Модель данных (упрощённо):

```rust
Snapshot      { providers: Vec<ProviderState>, fetched_at }
ProviderState { id, name, plan: Option<String>, status: Status,
                metrics: Vec<Metric>, fetched_at }
Status        = Ok | NotInstalled | Unauthenticated { hint }
              | RateLimited { until } | Error { message }
Metric        { id, label, used_pct: f64, resets_at: Option<DateTime<Utc>>,
                window_secs: Option<u64>, kind: Session | Weekly | Credits | Pool }
```

Цикл обновления: таймер → параллельный fetch всех включённых провайдеров
(таймаут 10 с каждый) → снапшот в кэш → событие во фронтенд. Ошибка одного
провайдера не влияет на остальные: для него остаётся предыдущее значение с
пометкой «устарело» и текстом ошибки.

## 6. Провайдеры

Принцип: приложение **никогда не спрашивает токены** — читает креды, уже
сохранённые CLI/IDE, и **ничего не пишет** в чужие хранилища. Эндпоинты
неофициальные, поэтому каждый парсер покрыт фикстурами.

### 6.1 Claude

| | |
|---|---|
| Креды | Keychain, сервис `Claude Code-credentials` (JSON `claudeAiOauth.accessToken / refreshToken / expiresAt / subscriptionType / rateLimitTier`); фолбэк `$CLAUDE_CONFIG_DIR/.credentials.json` → `~/.claude/.credentials.json` |
| Запрос | `GET https://api.anthropic.com/api/oauth/usage`, заголовки `Authorization: Bearer …`, `anthropic-beta: oauth-2025-04-20` |
| Метрики | `five_hour` → Сессия; `seven_day` → Неделя; `seven_day_sonnet` и `limits[kind=weekly_scoped]` → недельные лимиты по моделям (показывать, если присутствуют); `extra_usage` → Доп. использование (если включено). `utilization` — процент использованного, 0–100; `resets_at` — ISO-8601 |
| План | `subscriptionType` (Pro / Max) + множитель из `rateLimitTier` (`5x`, `20x`) |
| Истёкший токен | v1: не обновляем — refresh ротирует `refresh_token` и может разлогинить Claude Code. Показываем «Откройте Claude Code, чтобы обновить сессию», перечитываем Keychain на каждом цикле. Автообновление с атомарной записью обратно — v1.1, выключено по умолчанию |
| Ошибки | 401/403 → `Unauthenticated`; 429 → cooldown по `Retry-After` (иначе 5 мин); API-ключ вместо OAuth → «Лимиты недоступны для API-ключа» |

### 6.2 Codex

CLI, Codex.app и расширение IDE делят один логин и один лимит аккаунта ChatGPT —
показываем как одного провайдера.

| | |
|---|---|
| Креды | `$CODEX_HOME/auth.json` → `~/.codex/auth.json` (`tokens.access_token`, `tokens.account_id`); Keychain `Codex Auth`, если включён keyring-режим. Файл только с `OPENAI_API_KEY` → «Лимиты недоступны для API-ключа» |
| Запрос | `GET https://chatgpt.com/backend-api/wham/usage`, заголовки `Authorization: Bearer …`, `ChatGPT-Account-Id: …` |
| Метрики | `rate_limit.primary_window` (18000 с) → Сессия; `secondary_window` (604800 с) → Неделя; `additional_rate_limits[]` → доп. окна; `credits` → Кредиты (если есть). `used_percent` — использовано; `reset_at` — epoch-секунды; длину окна брать из `limit_window_seconds`, не хардкодить |
| План | `plan_type` (Plus / Pro / Team) |
| Фолбэк (v1.1) | последняя запись `event_msg / token_count.rate_limits` из свежего `~/.codex/sessions/**/rollout-*.jsonl` — без сети |
| Токены | не обновляем; Codex ротирует токен сам (≈ раз в 8 дней) |

### 6.3 Antigravity

| | |
|---|---|
| Источник v1 | Локальный language server запущенного Antigravity: процесс `language_server_macos` с `--app_data_dir antigravity`, флаг `--csrf_token`; порты через `lsof -nP -iTCP -sTCP:LISTEN -p <pid>`; проба `POST https://127.0.0.1:<port>/exa.language_server_pb.LanguageServerService/GetUnleashData` с заголовками `X-Codeium-Csrf-Token`, `Connect-Protocol-Version: 1`. TLS самоподписанный — доверять только для 127.0.0.1 |
| Данные | `RetrieveUserQuotaSummary` (группы «Gemini» и «Claude и GPT», окна 5 ч и неделя) → фолбэк `GetUserStatus` → `GetCommandModelConfigs` |
| Метрики | Gemini (сессия / неделя), Claude и GPT (сессия / неделя). В референсе показаны Gemini Pro / Gemini Flash / Claude по 5-часовому окну — точный набор фиксируется по реальному ответу на этапе 0 |
| План | тир из ответа (Google AI Pro / Ultra) |
| IDE не запущен | «Antigravity не запущен — откройте приложение или выполните `agy`» |
| Источник v1.1 | OAuth-токен Antigravity / `agy` из Keychain → `POST https://cloudcode-pa.googleapis.com/v1internal:retrieveUserQuota` (+ `loadCodeAssist` для тира). Refresh только в памяти — Google не ротирует `refresh_token`, записи обратно нет |

## 7. UI / UX

Панель ≈ 360 × 690 pt, открывается под иконкой меню-бара, закрывается по клику
вне панели или Esc, не активирует приложение (NSPanel).

Структура сверху вниз:

1. **Обзор использования** (v1.1) — вкладки «Сегодня / Вчера / 30 дней»,
   стековая полоса по моделям, легенда в две колонки (топ-4 + «Другие»),
   кнопки: вид по моделям / по проектам, экспорт.
2. **Секции провайдеров** в порядке из настроек. Заголовок: иконка, имя, справа
   бейдж плана («Google AI Pro», «Plus», «Max 5x»). Карточка с метриками:
   - строка: название («Сессия», «Неделя», «Gemini Pro» …) + точка статуса;
   - прогресс-бар остатка (заполнение = остаток) с маркером темпа — где должен
     быть остаток при равномерном расходе до сброса;
   - под баром: слева «Осталось 86 %», справа «Сброс сегодня в 6:36» /
     «Сброс завтра в 14:00» / «Сброс 11 сент. в 23:50»; окно без активности —
     «Не начато».
   - Состояния карточки: загрузка (скелетон), ошибка (текст + «Повторить»),
     устарело («обновлено 12 мин назад» серым).
3. **Футер**: слева «Перезапустить для обновления» (только когда обновление
   скачано, v1.2), справа «Следующее обновление через 3 мин» (клик — обновить
   сейчас).

Левый сайдбар: иконки провайдеров (клик — прокрутка к секции, индикатор следует
за прокруткой), внизу экспорт и настройки. Настройки открываются в этой же
панели.

Точка статуса: зелёная — остаток > 25 % и темп в норме; жёлтая — остаток ≤ 25 %
или расход опережает темп на 15+ п.п.; красная — остаток ≤ 10 % или лимит
исчерпан; серая — данных нет / устарели.

Меню-бар: монохромная template-иконка; опционально текст — остаток выбранной
метрики («C 86 %»). Правый клик: «Обновить», «Настройки…», «Выйти». Клавиши:
⌘R — обновить, ⌘, — настройки, Esc — закрыть.

Локализация: все строки в `src/i18n/ru.json` (en — позже), даты через `Intl` с
локалью `ru-RU`. Тема: `prefers-color-scheme`, по умолчанию система, можно
зафиксировать. Цветовые токены для обеих тем.

## 8. Обзор использования (v1.1)

Источник — локальные логи, без сети, инкрементальное сканирование
(кэш по mtime + размеру):

- Codex: `~/.codex/sessions/**/rollout-*.jsonl` —
  `event_msg / token_count.info.last_token_usage` (input, cached_input, output,
  reasoning), модель из `turn_context`.
- Claude: `~/.claude/projects/**/*.jsonl` — `message.usage` (input, output,
  cache_creation, cache_read) + `message.model`; дедуп по `message.id` +
  `requestId`.
- Antigravity: `~/.gemini/antigravity-cli/conversations/*.db` (SQLite) — схема
  уточняется на этапе 0.

Агрегация по дням (локальное время) и моделям; в легенде — доля токенов модели
за период. Оценка стоимости в $ по таблице цен — опционально (тумблер).

## 9. Настройки

Интервал обновления (1 / 5 / 15 / 30 / 60 мин, по умолчанию 5) · Запуск при
входе · Провайдеры: вкл/выкл, порядок, скрывать неустановленные · Меню-бар:
только иконка / иконка + %, выбор метрики · Тема: система / светлая / тёмная ·
Язык (ru) · Уведомления (v1.2) · Шорткат (v1.2, по умолчанию ⌃⌥U) ·
Экспериментально: автообновление токена Claude (v1.1).

Хранение: `~/Library/Application Support/Usage.ai/settings.json`, `cache.json`.

## 10. Уведомления (v1.2)

Порог использования (80 / 90 / 100 %), темп («при текущем темпе лимит
закончится за N ч до сброса»), сброс окна («Сессия Claude сброшена»). Дедуп в
рамках одного окна, «тихие часы».

## 11. Безопасность и приватность

- Токены не логируются и не сохраняются в наших файлах; читаются из источника
  на каждом цикле.
- Запись в чужие хранилища запрещена (v1).
- Сеть — только allow-list: `api.anthropic.com`, `chatgpt.com`,
  `cloudcode-pa.googleapis.com`, `127.0.0.1`. Телеметрии нет.
- Самоподписанный TLS принимается только для `127.0.0.1`.
- Первый доступ к Keychain может вызвать системный диалог — выбрать
  «Всегда разрешать».

## 12. Нефункциональные требования

CPU в простое ≈ 0 %, RAM < 100 МБ, открытие панели < 200 мс (из кэша), холодный
старт < 1 с, `.dmg` < 20 МБ. Любой сбой провайдера или парсера отражается
только в его карточке.

## 13. Тестирование и CI

- Unit-тесты парсеров на фикстурах (обезличенные реальные ответы), тесты
  планировщика с мок-провайдерами, тесты форматирования дат и статусов.
- `?mock=1` — UI на фейковых данных для скриншот-проверок.
- CI (ubuntu): `cargo fmt / clippy / test`, `pnpm lint / check / test / build`.
- Release (macos-14, arm64): `tauri build` → артефакт `.dmg`; по тегу `v*` —
  GitHub Release. В приватном репозитории macOS-минуты считаются ×10
  (≈ 200 мин/мес на Free); альтернатива — локально `pnpm tauri build`.
- Ручной чек-лист на Mac — критерии приёмки из раздела 15.

## 14. Сборка и дистрибуция

Без Developer ID — ad-hoc подпись. Скачанный из CI `.dmg` Gatekeeper пометит как
повреждённый → `xattr -cr "/Applications/Usage.ai.app"`; у локальной сборки
этого шага нет. Bundle identifier `com.nurasss.usageai`. Автообновление через
GitHub Releases + minisign-ключ Tauri — v1.2.

## 15. Этапы и критерии приёмки

| Этап | Содержание | Готово, когда |
|---|---|---|
| 0. Разведка (нужен ваш Mac) | Диагностический скрипт: какие креды / файлы / процессы есть, обезличенные ответы эндпоинтов → фикстуры | Есть фикстуры для всех трёх провайдеров |
| 1. Скелет | Tauri + Svelte, трей, панель с мок-данными, настройки, CI-сборка `.dmg` | Панель открывается на вашем Mac из скачанного `.dmg` |
| 2. Claude + Codex | Креды, запросы, парсеры, статусы, кэш | Цифры совпадают с `/usage` в Claude Code и `/status` в Codex |
| 3. Antigravity (LS) | Обнаружение процесса, порт, quota summary | Цифры совпадают с панелью квот в IDE |
| 4. Обзор токенов | Парсеры логов, агрегация, UI обзора | Итоги за сегодня совпадают с `ccusage` / аналогом ± 1 % |
| 5. Уведомления, шорткат, автозапуск, updater | — | Уведомление приходит при пересечении порога; шорткат работает |

## 16. Риски

- Неофициальные эндпоинты меняются → фикстуры + мягкая деградация.
- Схема Antigravity недокументирована → этап 0.
- Диалоги Keychain → инструкция пользователю.
- Gatekeeper без подписи → `xattr` / локальная сборка.
- Ротация токена Claude → в v1 не обновляем.

## 17. Идеи на потом

История использования (SQLite) и спарклайны · «Хватит до 18:40» рядом с
маркером темпа · Локальный HTTP API на 127.0.0.1 для Raycast / Stream Deck ·
Текст в меню-баре из нескольких провайдеров · Полностью локальный режим без сети
(statusLine-хук Claude + JSONL Codex) · Английская локаль.
