## 2. RC5 audit finding

The independent exact-tag RC5 audit verdict was `RELEASE HOLD — REMEDIATION REQUIRED`. It stopped at a P1 release-surface documentation defect in the tracked README, not at a new runtime coverage defect. The audited RC5 commit was `28d5115624b7f1c8555da940c9959721068b2723`.

The audit identified inaccurate claims about Gemini/Ollama support, blanket official quota APIs, Apple Silicon/universal builds, provider drivers, SQLite encryption, and Tailwind CSS. It also identified an evidence-path error in the RC5 report: the bundle executable is `Contents/MacOS/usage-ai-app`, not `Contents/MacOS/Usage.ai`. The RC5 audit intentionally did not accept the unrerun Rust, dataset, or packaged-runtime claims after its stop rule.

## 3. README Gemini/Ollama correction

`README.md` now states that v1.3 production scope is OpenAI Codex, Anthropic Claude Code, and OpenAI API when configured. Google Gemini/Gemini API is explicitly `Discovery only`, and Ollama is explicitly `Discovery/backlog only`; neither is presented as a shipped production driver or authoritative usage source.

## 4. Source-classification wording correction

The README now distinguishes source classes instead of claiming a single official quota API model:

- Codex uses the supported-client/App Server strategy and local structured history.
- Claude Code uses the provider-owned PTY/client strategy, OAuth usage where available, and local structured history.
- OpenAI API is available when the corresponding API account is configured.
- Provider-owned interfaces, supported client/App Server access, and local structured history remain visibly distinct.

The README retains the zero-inference statement: Usage.ai does not issue hidden generative requests and does not infer usage from model-response text.

## 5. Intel/Apple Silicon correction

The README now states the observed v1.3 release target precisely: `x86_64-apple-darwin` (Intel). It no longer claims an Apple Silicon or universal artifact. Apple Silicon qualification is outside this RC6 release gate and is not represented as a PASS.

## 6. Provider-driver correction

The provider table and workspace overview now describe production strategies only for Codex, Claude Code, and OpenAI API. Gemini and Ollama are described as discovery/backlog metadata without production drivers. No provider module, descriptor, or provider registry was changed in RC6.

## 7. SQLite/Keychain security correction

The README now says that usage/history are stored in ordinary local SQLite and does not claim database-level SQLite encryption. It scopes Keychain wording to secrets owned by Usage.ai, where applicable. Source-owned auth/session stores of other applications remain read-only from Usage.ai’s documented boundary.

## 8. Tailwind correction

The README now identifies the actual frontend stack as Svelte 5, TypeScript, Vite, CSS variables, and lightweight custom CSS/UI. The unsupported Tailwind claim was removed. A repository scan found no remaining positive Tailwind claim; remaining matches are factual negative or scoped statements only.
